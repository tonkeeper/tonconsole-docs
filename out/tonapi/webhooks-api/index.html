Webhooks API

Webhooks API provides a way to subscribe to events that happen in the TON blockchain. This allows you to build applications that react to events in the blockchain.

Authentication

All methods of Webhooks API require a private API key. You can get a personal API key at https://tonconsole.com/.

Webhooks API looks for an API key in two places in the following order:

  1. In the Authorization header with the "Bearer scheme". For example:

Webhook delivery

When an event happens, TONAPI sends a POST request to a webhook URL with the following headers:

  • Authorization carries the webhook's secret token, returned on creation and by the list method. Check it to make sure a request comes from TONAPI.
  • Idempotency-Key is the same for every delivery attempt of the same event, use it to deduplicate retries.

A delivery is successful when the endpoint responds with a 2xx status code. Otherwise the webhook becomes offline and TONAPI keeps retrying with growing intervals: every minute for the first 10 attempts, every 5 minutes up to 20 attempts, every 10 minutes up to 30 attempts and every hour after that. Retries stop after a week of failures. Use Mark a webhook back online to resume deliveries immediately.

If a webhook is created with add_transaction_info or add_account_info, the body additionally contains:

  • transaction - the transaction in the TONAPI Transaction schema;
  • account - the account in the TONAPI Account schema. balance, status and last_activity are as of right after the transaction, extra_balance, interfaces and get_methods are as of the delivery.

The Idempotency-Key is computed over the short body (without transaction and account).

API methods to manage webhooks

Create webhook

POST https://rt.tonapi.io/webhooks - the method creates a new webhook, configures its endpoint and returns a webhook ID and its secret token. A webhook ID is used to manage subscriptions.

A request body:

add_transaction_info and add_account_info are optional, see Account transaction event.

The method is idempotent: if a webhook with the same endpoint already exists, its ID is returned. If the existing webhook has different add_transaction_info or add_account_info, the method returns 409 Conflict, use Update a webhook to change them.

A response example:

List webhooks

GET https://rt.tonapi.io/webhooks - the method returns all available webhooks. A response example:

  • status - online, offline (deliveries fail and are being retried) or suspended (deliveries are stopped, e.g. due to insufficient balance);
  • status_updated_at - when the status last changed, for an offline webhook this is when the endpoint broke;
  • last_attempt_at - when the last delivery was attempted, successful or not;
  • status_failed_attempts - the number of failed delivery attempts since the webhook went offline.

Update a webhook

PATCH https://rt.tonapi.io/webhooks/{webhook_id} - the method changes a webhook's endpoint or options. At least one field is required.

A request body:

The method returns 409 Conflict if another webhook already uses the endpoint.

Delete a webhook

DELETE https://rt.tonapi.io/webhooks/{webhook_id} - the method deletes a webhook and all its subscriptions.

Generate a new webhook token

POST https://rt.tonapi.io/webhooks/{webhook_id}/generate-new-token - the method rotates the webhook's secret token.

A response example:

Mark a webhook back online

POST https://rt.tonapi.io/webhooks/{webhook_id}/back-online - the method marks a webhook as online and resumes deliveries without waiting for the next retry. For a suspended webhook it returns 402 Payment Required if the project balance is not positive.

Get webhook logs

GET https://rt.tonapi.io/webhooks/{webhook_id}/logs?offset=0 - the method returns failed delivery attempts and other webhook events. Pass next_offset from the response as offset to get the next page.

A response example:

event_type is one of account_tx, msg_opcode, new_contract, mempool_msg or suspended.

Get usage statistics

GET https://rt.tonapi.io/usage-stats - the method returns usage statistics for the current billing period.

Get a webhook's subscriptions

Subscribe to events about new contract deployments

POST https://rt.tonapi.io/webhooks/{webhook_id}/subscribe-new-contracts - when a new contract is deployed to the blockchain, TONAPI sends a POST request to the webhook URL.

Unsubscribe from events about new contract deployments

POST https://rt.tonapi.io/webhooks/{webhook_id}/unsubscribe-new-contracts - stop receiving a webhook notification when a new contract is deployed to the blockchain.

Subscribe to messages with a specific opcode in a message body

This subscription will trigger webhooks for every message on the blockchain that contains the specified opcode — even if it's unrelated to your accounts.

POST https://rt.tonapi.io/webhooks/{webhook_id}/subscribe-msg-opcode/0x{opcode} - when a new transaction is happening with a message that contains a specific opcode in its body, TONAPI sends a POST request to the webhook URL.

The number of opcode subscriptions per project is limited, the method returns 422 Unprocessable Entity when the limit is reached.

Unsubscribe from messages with a specific opcode in a message body

POST https://rt.tonapi.io/webhooks/{webhook_id}/unsubscribe-msg-opcode/0x{opcode} - stop receiving a webhook notification when a new transaction is happening with a message that contains a specific opcode in its body.

Get a webhook's opcode subscriptions

GET https://rt.tonapi.io/webhooks/{webhook_id}/msg-opcode/subscriptions?offset=0&limit=10 - limit is from 2 to 1000, 1000 by default.

A response example:

A subscription is disabled if its events fail to be delivered for two weeks. Subscribe again to re-enable it.

Subscribe to mempool events

POST https://rt.tonapi.io/webhooks/{webhook_id}/mempool/subscribe - when a new message appears in the mempool, TONAPI sends a POST request to the webhook URL.

Unsubscribe from mempool events

POST https://rt.tonapi.io/webhooks/{webhook_id}/mempool/unsubscribe - stop receiving a webhook notification when a new message appears in the mempool.

Testnet webhooks

Available by domain https://rt-testnet.tonapi.io/{ur_as_in_mainnet}
