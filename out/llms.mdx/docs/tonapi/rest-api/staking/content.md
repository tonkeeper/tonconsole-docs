# Staking (/tonapi/rest-api/staking)

[Open in Swagger UI](https://tonapi.io/api-v2#operations-tag-Staking)

The Staking service provides essential endpoints for interacting with staking pools on the network. It allows users to view and manage their participation in various staking pools.

## Operations [#operations]


- [`getAccountNominatorsPools`](https://tonapi.io/api-v2#operations-Staking-getAccountNominatorsPools) — All pools where account participates
- [`getStakingPoolInfo`](https://tonapi.io/api-v2#operations-Staking-getStakingPoolInfo) — Stacking pool info
- [`getStakingPoolHistory`](https://tonapi.io/api-v2#operations-Staking-getStakingPoolHistory) — Pool history
- [`getStakingPools`](https://tonapi.io/api-v2#operations-Staking-getStakingPools) — All pools available in network
