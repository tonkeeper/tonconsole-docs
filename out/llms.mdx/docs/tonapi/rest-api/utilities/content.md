# Utilities (/tonapi/rest-api/utilities)

[Open in Swagger UI](https://tonapi.io/api-v2#operations-tag-Utilities)

The Emulation methods offers tools for simulating the behavior of messages within the blockchain before they are actually sent. This service is particularly useful for developers and users who wish to test and verify the potential outcomes of their actions without committing them to the blockchain.

## Operations [#operations]


- [`addressParse`](https://tonapi.io/api-v2#operations-Utilities-addressParse) — parse address and display in all formats
- [`getOpenapiJson`](https://tonapi.io/api-v2#operations-Utilities-getOpenapiJson) — Get the openapi.json file
- [`getOpenapiYml`](https://tonapi.io/api-v2#operations-Utilities-getOpenapiYml) — Get the openapi.yml file
- [`status`](https://tonapi.io/api-v2#operations-Utilities-status) — Status
