# NFT (/tonapi/rest-api/nft)

[Open in Swagger UI](https://tonapi.io/api-v2#operations-tag-NFT)

The **NFT** service provides access to non-fungible tokens (NFTs) on the TON blockchain. This service enables retrieval of detailed information about NFTs, including metadata, ownership, and transaction history. NFTs are unique digital assets that represent ownership of various items, such as collectibles, art, and virtual real estate.

## Operations [#operations]


- [`getAccountNftHistory`](https://tonapi.io/api-v2#operations-NFT-getAccountNftHistory) — Get the transfer nft history
- [`getNftItemsByAddresses`](https://tonapi.io/api-v2#operations-NFT-getNftItemsByAddresses) — Get NFT items by their addresses
- [`getNftCollections`](https://tonapi.io/api-v2#operations-NFT-getNftCollections) — Get NFT collections
- [`getNftCollectionItemsByAddresses`](https://tonapi.io/api-v2#operations-NFT-getNftCollectionItemsByAddresses) — Get NFT collection items by their addresses
- [`getNftCollection`](https://tonapi.io/api-v2#operations-NFT-getNftCollection) — Get NFT collection by collection address
- [`getItemsFromCollection`](https://tonapi.io/api-v2#operations-NFT-getItemsFromCollection) — Get NFT items from collection by collection address
- [`getNftItemByAddress`](https://tonapi.io/api-v2#operations-NFT-getNftItemByAddress) — Get NFT item by its address
- [`getNftHistoryByID`](https://tonapi.io/api-v2#operations-NFT-getNftHistoryByID) — Please use `getAccountNftHistory`` instead
