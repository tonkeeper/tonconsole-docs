# DNS (/tonapi/rest-api/dns)

[Open in Swagger UI](https://tonapi.io/api-v2#operations-tag-DNS)

The **DNS** service provides access to the <a target="_blank" rel="noopener noreferrer" href={TONORG_LINKS.TONDNS_ABOUT}>TON DNS</a>. This service enables retrieval of detailed information about domain names, including ownership, expiration dates, and associated accounts. DNS is used to map human-readable domain names to blockchain addresses, facilitating interaction with accounts and services on the TON network.

## Operations [#operations]


- [`getAllAuctions`](https://tonapi.io/api-v2#operations-DNS-getAllAuctions) — Get all auctions
- [`getDnsInfo`](https://tonapi.io/api-v2#operations-DNS-getDnsInfo) — Get full information about domain name
- [`getDomainBids`](https://tonapi.io/api-v2#operations-DNS-getDomainBids) — Get domain bids
- [`dnsResolve`](https://tonapi.io/api-v2#operations-DNS-dnsResolve) — DNS resolve for domain name
